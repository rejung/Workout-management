# 07_Development_Roadmap (개발 로드맵 및 실행 단계)

본 문서는 구글 시트 Version 1에서 차세대 웹 버전으로 안전하게 전이하기 위한 마일스톤형 개발 실행 로드맵을 정의한다. 본 설계는 각 단계의 종결 조건을 명확히 선언함으로써 장기적인 개발 수명주기를 빈틈없이 가이드한다.

## 2. 단계별 세부 수행 임무 및 마일스톤

### Phase 1: 기준 분석 및 설계 가이드 수립 (완료)
* **목표**: Version 1 구글 시트의 모든 비즈니스 수식과 시트 구성을 해체 분석하고 정량 명세화한다.
* **산출물**: 8개의 핵심 마크다운 상세 설계서 편찬 및 전용 `/docs` 공간 격리.

### Phase 2: 무상태 도메인 연산 엔진 구축 (완료)
* **목표**: 스프레드시트의 꼬인 수식을 걷어내고, 확장 가능하고 독립적으로 작동하는 비즈니스 순수 연산 코드를 격리 제작한다.
* **산출물**: Epley 공식 엔진, 7일 이동평균 수식기, 4주/8주 트렌드 격차 가공 함수.

### Phase 3: UI 컴포넌트 마이그레이션 & 인터랙션 (진행중)
* **목표**: 대형 화면과 스마트폰 반응형 가로폭에 최적화된 미니멀리즘 뷰를 개발한다.
* **중점 세부과제**:
  * 모바일 친화형 4대 대종목 목표 달성률 게이지 및 3대 중량 위젯 카드.
  * 빠른 입력(Quick Input) 탭의 지연 없는 숫자 포커스 전송 양식.
  * 날짜 역순 타임라인 테이블 및 종목별 상세 훈련 빈도 분석 바.

### Phase 4: 유틸리티 및 오프라인 저장소 통합 (예정)
* **목표**: 장시간 훈련 일지를 축적해도 브라우저 메모리 초과나 유실이 없고, 이관이 자유로운 완벽한 로컬 저장 모델을 구현한다.
* **중점 세부과제**:
  * JSON 무손실 내보내기 및 덮어쓰기 기능 구현 (FN-SY-01).
  * 주간 평균 체중 요약 통계 엔진 완수.

### Phase 5: 영속성 계층 최종 선정 및 클라우드 결합 (미래)
* **목표**: 복수의 모바일 디바이스나 웹 브라우저 캐시 클리어 상황에서도 영구 동기화될 수 있는 클라우드 데이터베이스를 결정하고 안전하게 바인딩한다.
* **비고**: 기술 도입은 본 애플리케이션의 핵심 무상태 연산이 100% 검증 완료된 이후에, 데이터 이전에 대한 충분한 대비책을 안고 수행한다.
