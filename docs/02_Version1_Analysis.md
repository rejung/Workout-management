# 02_Version1_Analysis (구글 시트 버전 1 구조 분석)

---

## 1. Version 1 개요 및 시트별 역할
구글 시트 기반의 Version 1은 엑셀 수식과 차트 기능을 최대로 활용하여 실시간 지표 분석 및 고속 입력을 결합한 지능형 데이터 시트이다. 사용자가 하나의 구글 드라이브 내에서 모바일과 데스크톱을 오가며 사용할 수 있도록 극도의 미니멀리즘과 스프레드시트 특유의 선형 입력성을 유지하고 있다.

### 1.1. Dashboard (종합 분석 보드)
* **목표 및 역할**: 현재 사용자의 가장 즉각적인 신체 조건, 대표 종목의 기량 성과, 최근 트렌드를 종합 대시보드 형태로 일안(Single View)에 파악할 수 있는 관제탑 역할을 수행한다.
* **구성 위젯 및 분석 데이터**:
  * **최근 4주 변화 요약**: "체중 변화, 스쿼트, 벤치프레스, 데드리프트, OHP"의 4주 전 대비 상대 격차를 한 줄의 평문 요약으로 상단에 표출하여 직관적 피드백 제공.
  * **핵심 강도 지표 (e1RM & 3-Lift)**: 
    * 현재 체중 및 이전 대비 증감값 (+/- kg 표시).
    * 스쿼트, 벤치프레스, 데드리프트, OHP 등 4대 종목별 현재 추정 1RM(e1RM), 설정한 개인 최고 목표치, 목표 대비 달성률(%) 표출.
    * 3대 합계(스쿼트 + 벤치프레스 + 데드리프트 e1RM 합산) 및 목표치 대비 달성 백분율 시각화.
  * **대표 작업중량 변화**: 각 종목의 메인 작업 세트 중량(Working Weight) 기준 현재값, 4주 전값, 순수 변화량(kg), 변화율(%), 개인 목표치 정합 비교 테이블.
  * **종목별 훈련 빈도**: 최근 4주 누적 수행 횟수와 최근 8주 누적 수행 횟수를 추적하여 현재 루틴의 빈도 성실성 파악.
  * **러닝 마일리지**: 유산소 능력 관리를 위해 최근 4주, 최근 8주, 전체 누적 러닝 거리를 기록 및 시각화.
  * **추정 1RM 변화 추이**: 최근 4주 변화량 및 최근 8주 변화량을 정량적으로 기재.
  * **최고 품질 작업세트 (Best Quality Worksets)**: 역대 최고 중량×반복×세트 구성을 종목별로 분석해 내고, 해당 성과를 기록한 역사적 날짜를 명시함으로써 성취감 극대화.

### 1.2. 빠른 입력 (Quick Input Page)
* **목표 및 역할**: 운동 도중 혹은 체중계 위에서 복잡한 시트 전환 없이 고속으로 입력을 처리하는 간이 폼 양식이다.
* **입력 필드**:
  * 체중 기입 필드 및 단일 전송 버튼.
  * 운동 입력 폼: 종목 선택 드롭다운, 중량(kg) 슬라이더/인풋, 세트수 인풋, 반복수 인풋 및 전송 버튼.
  * 최근 저장 이력: 사용자가 방금 무엇을 기입했는지 타임스탬프와 함께 피드백해주는 리스트 박스 제공.

### 1.3. 운동 기록 (Raw Log Sheet)
* **목표 및 역할**: 운동 날짜, 종목명, 무게(kg), 세트 수, 세트당 반복 수, 추가 러닝 거리 및 시간 정보가 시간 순(Chronological)으로 무한히 적치되는 저장소 시트.
* **특이 수식 구성**:
  * 각 레코드 옆에 자동으로 1RM 공식이 가동되어 해당 세트의 강도적 우수성을 개별 필터링할 수 있는 논리 구조 구축.

### 1.4. 체중 기록 (Weight Log Sheet)
* **목표 및 역할**: 날짜별 체중(kg) 로데이터를 적치하는 전용 시트로, 7일 평균값(주간 평균 요약) 슬라이딩 수식이 연계되어 일일 체중 편차에 일희일비하지 않도록 가이드한다.

## 2. 데이터 가공 및 연산 흐름 (Data Pipeline)
Version 1의 진정한 가치는 엑셀 수식 기반의 수학적 분석 흐름에 있다.

```
[원시 훈련 입력 (중량 W, 반복 R, 세트 S)]
               │
               ▼
   [Epley 공식을 통한 e1RM 연산]
    e1RM = W * (1 + R / 30) (단, R > 1 일때)
               │
               ▼
[최근 4주 데이터 세트 서브샘플링 필터]
   ├── 4주 내 최고 e1RM 추출
   ├── 최근 4주간 주당 평균 빈도 연산
   └── 4주 전 e1RM과의 델타값 연산
               │
               ▼
  [최종 Dashboard 지표 셀 업데이트]
```

## 3. Version 1의 구조적 장단점

### 3.1. 장점 (Strengths)
* **데이터 투명성**: 모든 로데이터와 연산 수식이 시트 내에 노출되어 있어 연산의 오차나 누락이 없다.
* **유연한 스케일링**: 구글 스프레드시트의 필터 기능과 피벗 테이블을 통해 원하는 뷰를 사용자가 직접 수정/제작할 수 있다.
* **클라우드 동기화**: 구글 계정만 있으면 언제 어디서든 실시간 동기화 상태가 유지된다.

### 3.2. 한계점 (Limitations)
* **모바일 입력 경험 최악**: 스마트폰 가로 너비 제약으로 인해 구글 시트 앱에서 숫자를 오타 없이 정확하게 빠르게 입력하는 것이 고통스럽다.
* **성능 한계**: 데이터 행이 1,000행을 넘어가기 시작하면서 인덱스 수식과 피벗 연산의 지연 시간(Lag)이 발생하여 차트 렌더링 속도가 저하된다.
* **유효성 검증 부재**: 텍스트 필드에 오타(예: 종목명 "벤치프레스"를 "벤치프레쓰"로 오기입)가 발생하면, 통계 차트에서 해당 데이터가 유실되어 수동 정제가 정기적으로 필요하다.

## 4. Version 2에서 반드시 계승해야 하는 정수 (Core Pillars)
웹 애플리케이션으로 마이그레이션되더라도 다음 설계 요소는 타협 없이 100% 보존 및 발전시켜야 한다.

1. **Epley 공식의 엄격한 준수**:
   * 강도 지표 산출의 통일성을 위해 $\text{e1RM} = W \times (1 + R / 30)$ 공식을 엄밀하게 일관 적용한다. (단, 1회 반복인 경우는 무게 자체가 e1RM이 됨)
2. **4주 및 8주 기반의 단기/중기 트렌드 델타 분석**:
   * 단순 전체 평균이나 최고 기록만을 보여주는 것은 현재 수준 분석에 악영향을 준다. 반드시 '최근 4주 트렌드'를 비교 분석하는 창을 핵심적으로 제공한다.
3. **최고 품질 작업세트 정의**:
   * 최고 e1RM뿐만 아니라 실질적인 훈련 볼륨의 성숙도를 보여주는 지표이므로, 역대 최고 난이도 및 퀄리티를 유지한 '중량×반복×세트' 기록을 각 대종목별로 파악하는 로직을 지켜낸다.
4. **유산소(러닝)와 무산소(SBD+OHP)의 통합 관리**:
   * 한쪽의 운동 일지에만 편향되지 않도록 유산소 마일리지 집계 큐와 근력 지표 큐를 균형 있게 노출한다.
