# 06_UI_UX_Specification (UI/UX 디자인 가이드 및 화면 설계)

본 문서는 현대적인 웹 브라우저 및 모바일 기기 스크린 환경에서 최상의 터치 기입 경험과 가독성을 이끌어내기 위한 UI/UX 설계 원칙을 선언한다. 디자인 철학은 복잡성을 철저히 제한하고 정량 정보를 우아하게 제공하는 **"스위스 모던 스타일(Swiss Modern Minimalist Style)"**에 입각한다.

---

## 1. 모바일 중심 디자인 가이드라인 (Mobile-Focused UX)
* **손쉬운 터치 영역 보장 (Touch Target Compliance)**:
  * 모바일 기기 한 손 조작성을 위해 모든 인터랙티브 컨트롤(버튼, 입력 필드, 드롭다운 토글)의 높이 및 너비는 최소 **44px × 44px** 이상을 준수한다.
  * 입력 필드 간의 마진(Gap)을 충분히 보장하여 불필요한 인접 항목 오클릭을 완벽히 소거한다.
* **레이아웃 반응형 그리드 체계 (Fluid Layout)**:
  * 모바일 스크린 크기(320px ~ 480px)에서는 수직으로 길게 구성된 한 화면(Single-Column Grid) 형태를 충실히 보전한다.
  * 데스크톱 및 태블릿(1024px 이상)에서는 넉넉한 여백(Negative Space)을 보전하고 좌측 유틸리티 영역과 우측 모니터 뷰로 구성된 다단 그리드(Multi-Column Grid)로 미려하게 전환한다.
* **텍스트 가독성 (High Contrast Typography)**:
  * 체육관의 어두운 조명 아래에서도 지표가 왜곡 없이 눈에 띄도록 대비가 높고 명료한 흑백 대비 색조(Deep Slate Background와 Off-White Text)를 지향한다.

## 2. 사용자 핵심 흐름 (User Flow Map)

```
[사용자 입장: 체육관 또는 아침 기상]
              │
              ▼
    [01. 일일 체중 측정 단계]
    - 빠른 입력(Quick Input) 접속
    - 체중 수치 기입 후 단일 버튼으로 5초 이내에 전송
              │
              ▼
    [02. 본격적인 근력 훈련 가동]
    - 대시보드의 '최고 품질 작업세트' 카드로 오늘의 목표 무게 파악
    - 한 세트가 끝날 때마다 '운동 입력' 폼을 활용해 중량/반복수 즉시 기입
              │
              ▼
    [03. 실시간 통계 업데이트 검토]
    - 세트 입력과 동시에 e1RM 달성율 게이지 바가 상승하는 시각적 쾌감 획득
    - 최근 4주 전 대비 스트렝스 실시간 추이(델타값) 확인
              │
              ▼
    [04. 퇴장 및 요약 피드백]
    - 오늘 누적된 성과 타임라인 스크롤하며 검토
```

## 3. 화면별 설계 원칙 (Design Principles)

### 3.1. 대시보드 설계 원칙 (Dashboard Rules)
* **지표의 수직적 위계 (Visual Hierarchy)**:
  * 가장 중요한 3대 운동 e1RM 및 3대 총합 중량(3-Lift Total)을 대형 타이포그래피(Display Size 32px 이상)로 최상단에 배치해 사용자 시선을 먼저 장악한다.
  * 하위 속성은 `JetBrains Mono` 폰트 기반의 모노스페이스 서체 스타일을 도입하여, 수치의 과학적 정밀함과 공학적인 직관성을 동시에 유도한다.
* **고밀도 훈련 테이블 가독성**:
  * 테이블의 줄 간격(Row Padding)을 편안하게 조정하고, 증감 추이를 지시하는 부호(+, -)와 색상 가이드(상승은 Green, 보존은 Slate Gray)를 시인성 높게 연동한다.

### 3.2. 빠른 입력 폼 설계 원칙 (Quick Input Form Rules)
* **지연 제로 기입 경험 (No Latency Interface)**:
  * 모바일 가상 키보드가 브라우저 뷰포트를 가리거나 밀어내지 않도록 단순한 원페이지 스크롤 고정형 레이아웃을 제공한다.
  * 입력 후 마우스나 손가락을 이동시키지 않아도 디폴트 액션이 완료되는 '포커스 가속 패치'를 마련한다. (예: 체중 수치 입력 후 Enter 키만으로 자동 전송 처리)
* **입력 유효성 피드백 (Toasts & Notifications)**:
  * 데이터 입력 완료 시 "데이터가 성공적으로 전송되었습니다." 문구와 기입 시간이 폼 하단 '최근 입력 이력' 미니 카드 영역에 조용하게 업데이트된다. 이는 시끄러운 모달 팝업 대신 유연한 상태 변화로 안심감을 선사한다.

## 4. UI 테마 및 스타일 규격
* **서체 쌍 (Typography Pairings)**:
  * **일반 텍스트 및 UI 컨트롤**: `Inter` (Legibility 중심의 고품격 산세리프)
  * **수치 정보, 타임스탬프, 물리량**: `JetBrains Mono` (엔지니어링 테마의 높은 서체 고유 너비 정합성)
* **컬러 팔레트 (Color Palette)**:
  * **Background**: `bg-slate-950` (야간 및 어두운 실내에서 눈의 피로를 최소화하는 우아한 딥 다크 캔버스)
  * **Surface/Card**: `bg-slate-900 / border-slate-800` (고대비 표면을 위한 세련된 카드 프레임)
  * **Accent Color**: `text-emerald-400 / bg-emerald-500` (목표 달성 시 축하하는 시그널과 점진적 부하 증가 성공을 알리는 네추럴 에메랄드)
