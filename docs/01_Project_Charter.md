# 01_Project_Charter (프로젝트 헌장)

---

## 1. 프로젝트 목적 (Project Purpose)
본 프로젝트는 구글 시트(Google Sheets) 기반으로 구축되어 오랜 기간 실질적인 효과가 검증된 개인 훈련 의사결정 지원 도구인 **Version 1**을 계승하고, 이를 현대적이고 뛰어난 사용성을 갖춘 독립 웹 애플리케이션인 **Version 2**로 재설계 및 고도화하는 것을 목적으로 한다.

단순한 일방적 운동 기록(Log) 저장소를 넘어, **"데이터 입력 → 데이터 가공 → 정량 분석 → 시각화 피드백 → 점진적 과부하 설계"**로 이어지는 선순환 고리를 극대화하여 훈련자가 매 세션마다 과학적이고 객적인 근거를 기반으로 다음 단계의 중량 및 볼륨 오버로드를 결정할 수 있도록 지원하는 지능형 시스템을 구축한다.

---

## 2. 개발 철학 (Development Philosophy)
* **설계 우선 원칙 (Design-First Approach)**
  * 코드를 바로 작성하지 않고 설계 목적과 원칙을 먼저 논리적으로 정의한다.
  * 기술적인 기교나 복잡한 라이브러리 도입보다 데이터의 정합성과 유지보수성이 우선한다.
* **기준 모델 존중 (Respect Reference Implementation)**
  * 수개월 이상 수집되어 성능이 검증된 Version 1(구글 시트)의 데이터 가공 공식과 로직을 절대적인 규칙이자 참조 명세서(Source of Truth)로 사용한다.
* **불필요한 기능 제거 (Anti-Overengineering)**
  * 사용자 요구나 실사용 사례가 검증되지 않은 복잡한 AI 피드백, 자동 추천 알고리즘, 복잡한 알림 시스템 등은 배제한다.
  * 훈련의 핵심인 **"기록의 편의성"**과 **"추정 1RM 트렌드 추적"**이라는 핵심 본질에 모든 역량을 집중한다.
* **결정의 유연성 (Architecture Agnosticism)**
  * 데이터 저장 메커니즘이나 인프라 환경은 초기 단계에 고정하지 않으며, 무상태(Stateless) 도메인 레이어 설계를 바탕으로 언제든지 교체 가능한 영속성 계층(Persistence Layer) 구조를 지향한다.

## 3. 프로젝트 범위 (Project Scope)

### 3.1. 포함 범위 (In-Scope)
* **신속한 기입 시스템 (Quick Input)**: 한 화면에서 체중 및 운동 세트를 지연 없이 빠르게 입력할 수 있는 구조.
* **실시간 훈련 지표 가공 (Live Analytics Pipeline)**: 입력된 로데이터를 기반으로 추정 1RM(e1RM), 누적 볼륨, 주당 평균 빈도, 최고 품질 작업세트 등을 실시간 연산 및 동기화.
* **체중 및 훈련 통계 일지**: 장기적인 체중 변화 그래프 및 상세 훈련 기입 히스토리 조회.
* **데이터 이동성 (Data Portability)**: 오프라인/로컬 퍼스트 환경에서도 유실이 없도록 JSON 기반 무손실 백업 및 복원 기능 지원.

### 3.2. 제외 범위 (Out-of-Scope - 향후 검토)
* 머신러닝 기반 자동 운동 시퀀스/루틴 추천
* 커뮤니티 및 소셜 공유, 경쟁 기능
* 네이티브 모바일 푸시 알림 및 모바일 센서 연동
* 외부 웨어러블 기기(Garmin, Apple Watch 등) API 실시간 직접 연동

---

## 4. 프로젝트 목표 (Project Goals)
* **정량적 목표**
  * 모바일 디바이스에서 운동 중 1개 세트 기록을 완료하는 시간을 **5초 이내**로 단축 (신속한 인터랙션 제공).
  * 6주 이상의 복합 다관절 운동 데이터 축적 시, 부위별 훈련 밸런스와 추정 1RM의 증감 성과를 시각적으로 즉각 도출.
  * 플랫폼 간 전환(웹, 로컬 앱 등)이 용이하도록 완벽히 표준화된 JSON 데이터 스키마를 수립.
* **정성적 목표**
  * 훈련자에게 '기록을 위한 귀찮은 행위'가 아닌 '다음 훈련 중량 결정을 위한 설레는 분석'으로 인식을 전환시킴.
  * 장기적인 유지보수성과 확장성이 우수한 도메인 모델을 확립하여 개발 생산성을 지속 유지.

---

## 5. 이번 버전 (Version 2.0)의 초점
웹 애플리케이션 아키텍처로의 전환을 완수하고, Version 1의 수식과 가공 기능을 웹에 완벽하게 내재화하는 것을 목표로 한다.
화려한 그래픽보다 **"고대비 라이트/다크 테마의 높은 가독성"**, **"모바일 화면에서의 터치 최적화"**, **"정확한 Epley 공식 기반 1RM 분석 및 볼륨 추이 표현"**에 주안점을 둔다.
