# 03_Feature_Specification (기능 요구사항 명세서)

본 명세서는 구글 시트 Version 1에 존재하는 기능만을 누락 없이 체계적으로 정제하여 고유한 **Feature ID**를 부여한 산출물이다. 신규 피처나 확정되지 않은 고급 기능은 본 명세서에서 명확히 배제한다.

---

## 1. 종합 대시보드 모듈 (Dashboard Module)

### FN-DB-01: 실시간 4주 성과 한 문장 요약 (4-Week Summary Alert)
* **설명**: 사용자의 최근 4주간 체중 증감과 4대 종목(스쿼트, 벤치프레스, 데드리프트, OHP)의 e1RM 변화 추이를 대시보드 최상단에 마이크로 카피(평문 한 문장)로 자동 가공하여 인쇄한다.
* **입력 데이터**: 최근 4주간의 훈련 로그 및 체중 로그 데이터.
* **산출 형식**: `"최근 4주 변화 요약: 체중 [X]kg, 스쿼트 [Y]kg, 벤치프레스 [Z]kg, 데드리프트 [A]kg, OHP [B]kg"` (증감 기호 필수).

### FN-DB-02: 4대 종목 추정 1RM(e1RM) 및 3대 중량 통계 (e1RM & 3-Lift Total Widget)
* **설명**: 개별 종목의 현재 추정 최고 e1RM, 설정 목표 중량, 그리고 목표 달성률(%)을 병렬식 카드로 표시하며, 스쿼트+벤치프레스+데드리프트의 현재 e1RM 합산을 통해 최종 3대 중량 위젯을 자동 집계한다.
* **연산 공식**:
  * $\text{e1RM} = \text{무게} \times (1 + \text{반복} / 30)$ (단, 반복이 1회일 때는 순수 무게값 적용).
  * 3대 중량 = 스쿼트 최고 e1RM + 벤치프레스 최고 e1RM + 데드리프트 최고 e1RM.
  * 목표 달성률 = $(\text{현재 e1RM} / \text{목표 중량}) \times 100$.

### FN-DB-03: 대표 작업중량 성과 정밀 대조 테이블 (Working Weight Comparative Table)
* **설명**: 보조 수단이 아닌 훈련의 '메인 세트(대표 작업세트)' 중량에 대해 현재 수준, 4주 전 수준, 수치 변화, 백분율 성패, 목표 수치와의 정합성을 매트릭스 형태로 제공한다.
* **출력 열**: 종목, 현재 중량, 4주 전 중량, 변화량(kg), 변화율(%), 개인 최종 목표.

### FN-DB-04: 주 단위 종목별 수행 빈도 추적기 (Training Frequency Analyzer)
* **설명**: 각 종목의 훈련 볼륨 투입 주기를 정량화하기 위해 최근 4주간 해당 종목을 수행한 총 일수와 최근 8주간 수행한 일수를 비교 표출한다.
* **출력**: 스쿼트/벤치프레스/데드리프트/OHP별 최근 4주 빈도(회), 최근 8주 빈도(회).

### FN-DB-05: 러닝 누적 마일리지 통계 카드 (Cardio Mileage Tracker)
* **설명**: 무산소뿐만 아니라 러닝 기록에 대한 총량 관리를 위해 최근 4주 누적 거리, 최근 8주 누적 거리, 전 유산소 여정의 총 누적 거리를 대조 표현한다.

### FN-DB-06: 최고 품질 작업세트 시각화 (Best Quality Worksets Display)
* **설명**: 1회만 들어 올리는 극한의 1RM 시도 외에, 실제로 몸의 스트렝스 향상을 가장 강력하게 견인한 "고중량×고반복×고세트" 조합을 역대 로그에서 선별하여 해당 훈련 세트 구조와 달성한 타임스탬프 일자를 4대 운동별로 독립적으로 인쇄한다.

## 2. 고속 데이터 기입 모듈 (Quick Input Module)

### FN-QI-01: 실시간 단일 체중 기입 양식 (Quick Weight Entry Form)
* **설명**: 사용자가 훈련장 입장 전 혹은 기상 직후 빠르게 체중만을 별도로 기입하여 영속성 디바이스로 송출하는 초간편 입력 폼.
* **구성 필드**: 체중 숫자 필드(kg), 기입 전송 인터랙터.

### FN-QI-02: 종목 세트 기입 양식 (Quick Workout Set Entry Form)
* **설명**: 단일 훈련 단위를 고속으로 입력하기 위한 단순 구조 인터페이스로, 불필요한 스무 단계의 하위 폼을 거치지 않고 종목, 중량, 반복수, 세트수를 한번에 매핑하여 최종 적치소로 전송한다.
* **구성 필드**: 운동종목 선택(드롭다운 리스트), 무게(kg), 세트 수, 반복 수, 단일 가동 확인 인터랙터.

### FN-QI-03: 최근 입력 이력 및 기입 상태 모니터 (Recent Input Feedback Hub)
* **설명**: 퀵 인풋 완료 시 사용자가 성공적으로 데이터가 적재되었는지 실시간으로 확인할 수 있도록 최근 체중 입력 레코드 1건과 최근 운동 입력 레코드 1건의 값 및 전송 완료 타임스탬프를 폼 바로 아래에 미니 카드로 노출한다.

## 3. 원시 데이터 기입 및 이력 조회 모듈 (Raw Logs Hub)

### FN-HS-01: 날짜 역순 운동 히스토리 타임라인 (Workout History Timeline)
* **설명**: 기입된 원시 훈련 행렬을 날짜 최신순(역순)으로 스크롤 가능한 테이블로 렌더링한다.
* **출력 데이터**: 날짜, 종목명, 무게(kg), 세트, 반복 수, 거리(러닝인 경우), 시간(러닝인 경우).

### FN-HS-02: 종목 및 강도 필터링 탐색기 (Workout Log Advanced Filter)
* **설명**: 수천 개의 훈련 데이터 속에서 특정 타겟 대종목(SBD 및 기타)만 골라내거나, 특정 시점의 훈련 양상을 검토할 수 있는 실시간 검색 및 필터 구조.

### FN-HS-03: 체중 기록 데이터 연대기 테이블 (Weight Chronicle Table)
* **설명**: 수집된 체중 데이터를 날짜, 일일 체중(kg)의 단순 행태로 역순 정렬하여 보여주는 조회 뷰.

### FN-HS-04: 체중 이동평균(7-Day Moving Average) 연산 및 주간 요약 통계
* **설명**: 체중의 급격한 일일 변동성에 따른 인지 편향을 제거하기 위해, 특정 날짜의 기록을 기준으로 앞뒤 7일간의 이동평균값을 자동 산출하여 주차별 평균 체중을 별도의 통계 테이블로 계산 및 제공한다.

## 4. 데이터 이동성 및 무결성 제어 (Data & System Utility)

### FN-SY-01: 데이터 전체 JSON 백업 및 복원 (JSON Backup & Import)
* **설명**: 구글 시트의 뛰어난 이식성(엑셀 다운로드 등)을 보완하기 위해 웹 상에서 동작하는 전체 데이터베이스를 하나의 JSON 문자열 구조로 완전히 내보내거나, 외부 JSON 파일을 읽어 들여 데이터를 유실 없이 완벽히 복원하는 오프라인 안전장치.
* **데이터 포맷**: 운동 세트 배열 및 체중 이력 배열이 정의된 구조화된 스키마.
